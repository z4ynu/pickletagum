# Design direction — locked

**Palette.** Deep `#123B32` (night-court green) is the structural color, balanced by a warm eggshell `#F7F4EA` surface and a bright pickleball yellow `#D9E94D` accent. Coral `#EF8062` is reserved for the independent-directory notice. This keeps the sport reference lively without relying on the familiar neon-green-on-black treatment.

**Type pairing.** `DM Sans` provides direct, compact utility copy; `Bodoni Moda` provides the editorial display voice for location-led headings. The contrast lets the page feel local and considered rather than like a generic booking app.

**Signature element.** Court cards have a *rally strip*: a tiny court-line diagram whose color identifies the booking route (direct site, PickleHub, Facebook, or phone). It repeats in the filter count and gives the directory a visual system without needing stock imagery.

**Shape and motion.** Use mostly squared-off surfaces with one softened corner, deliberately varied radii, and a 160ms lift/outline transition on interactive elements. The mobile layout is the reference layout; larger screens simply add columns.
